Now that your creation looks like a TaTaCon, you need to upload the firmware to the Arduino so it acts like one!

## Firmware Options

There are a few firmware options available:

1. **[LuiCat's ArduinoTaikoController](https://github.com/LuiCat/ArduinoTaikoController)** — The original firmware I used. However, I had issues with double inputs and misinputs.

2. **[judjdigj's LeonardoTaiko](https://github.com/judjdigj/LeonardoTaiko)** — A well-developed and improved version. Recommended if you want a polished experience.

3. **My custom firmware** (below) — A temporary firmware that works better for me, but note it is a work-in-progress. It features dynamic threshold adjustment and per-sensor sensitivity calibration.
